Built for speed, flexibility, and control, it unifies billing, inventory, reporting, and multi-device coordination under a single platform across Windows and Android devices.

## 🌟 Overview

One Stop POS simplifies daily business operations through an intuitive interface and a robust feature set. Whether operating from a desktop cashier station or a handheld mobile tablet, the system ensures seamless transaction handling, real-time inventory updates, and insightful business reporting.

* **Multi-Device Support:** Connect and synchronize up to **17 devices** simultaneously.
* **Rich Feature Set:** Equipped with **70+ built-in features** for billing, stock, and operational control.
* **Cross-Platform:** Native-feeling experience on both desktop Windows systems and mobile Android APKs.

## ⚙️ System Requirements

### Windows
* **OS:** Windows 10 or later
* **Processor:** Dual-core processor or higher
* **RAM:** 4 GB minimum recommended
* **Storage:** 500 MB free disk space
* **Network:** Active network connection (required for multi-device synchronization)

### Android APK
* **OS:** Android 8.0 (Oreo) or later
* **RAM:** 3 GB minimum recommended
* **Storage:** 250 MB free disk space
* **Permissions:** Storage, Network, and Bluetooth/Printer permissions
* **Network:** Active network connection recommended for synchronized operations

## 🚀 Installation

### Windows Setup
1. Download the latest `One Stop POS` Windows installer executable (`.exe`).
2. Right-click the setup file and select **Run as Administrator**.
3. Follow the on-screen wizard instructions.
4. Launch the application upon installation completion.
5. Perform initial business and store configuration.

### Android APK Setup
1. Download the `One Stop POS` APK file to your device.
2. Enable **Install from Unknown Sources** in your device security settings if prompted.
3. Open the downloaded `.apk` file to begin installation.
4. Open the application once installed.
5. Configure store profiles, staff accounts, and network device connections.

## ✨ Key Features

One Stop POS contains over **70+ features** categorized into core operational modules:

* **💳 Billing & Sales:** Fast checkout, instant invoice generation, flexible tax settings, custom discounts, and multi-payment method acceptance.
* **📦 Inventory Management:** Real-time stock tracking, item categorization, barcode support, low-stock alerts, and batch management.
* **📊 Reports & Analytics:** Comprehensive daily sales breakdowns, stock movement reports, user activity logs, and financial transaction summaries.
* **🔐 User & Access Control:** Role-based permissions, cashier shift management, secure login, and operational audit trails.
* **👥 Customer & Business Management:** Customer profiles, purchase history tracking, store counter configurations, and loyalty insights.
* **🖨️ Hardware & Device Integration:** Thermal printer support, barcode scanner integration, and multi-terminal data sync.
